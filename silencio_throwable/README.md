# CritConversion (Surplus Crit Chance to Crit Damage)

Also applies the critical hit chance and damage from the "Silencio" weapon mod to thrown attacks.

## Install
1. Install / Update [TweakXL](https://www.nexusmods.com/cyberpunk2077/mods/4197) (and its dependencies).
2. Download and extract the mod from here.
3. Drag the r6 folders into your "Cyberpunk 2077" game folder.

## Usage
Put the ["Silencio"](https://cyberpunk.fandom.com/wiki/Silencio) weapon mod on any throwable weapon, throw it while being undetected, and crouching and profit from the mod's crit chance and damage.

## Uninstall
Close the game and delete the "throwablesilencio" folder from:
```
"Cyberpunk 2077\r6\tweaks"
```
    
## Notes
* Tested only in a controlled environment.
* Only indication of this mod working is the weapon mod type being "Throwable" now.
* The weapon mod should also still apply to melee hits from an undetected and crouched state (like vanilla).
