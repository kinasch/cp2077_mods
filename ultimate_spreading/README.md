# Ultimate Spreader
## About this mod

Lets you edit every (spreadable) quick hack's spread values, such as count and range (also bonusJumps in the CET version).
Does make quick hacking even more broken than it already is.

## Versions
There exist two versions:
| Requirements | NexusMods page |
| --- | --- |
| [CET](https://www.nexusmods.com/cyberpunk2077/mods/107) | https://www.nexusmods.com/cyberpunk2077/mods/5847 |
| [redscript](https://www.nexusmods.com/cyberpunk2077/mods/1511) and [Mod Settings](https://www.nexusmods.com/cyberpunk2077/mods/4885) | N/A |

You can use both, they do not interfere with each other, but I would recommend choosing one.

## Installation
### CET version:
1) Install / Update [Cyber Engine Tweaks](https://www.nexusmods.com/cyberpunk2077/mods/107).
2) Download and extract the mod from here.
3) Drag **only** the `bin` folder into your "Cyberpunk 2077" game folder.

### redscript version:
1) Install / Update [redscript](https://www.nexusmods.com/cyberpunk2077/mods/1511) and [Mod Settings](https://www.nexusmods.com/cyberpunk2077/mods/4885).
2) Download and extract the mod from here.
3) Drag **only** the `r6` folder into your "Cyberpunk 2077" game folder.

## Usage
### CET version:
- Open the Cyber Engine Tweaks Console and, in the Ultimate Spreader window, change the values for the specific quick hack under the specific quick hack category (you can resize the window).
- Bonus Jumps are kind of the same as Spread Count (10 bonus jumps and 15 spread count would mean 25 spreads).
- Above a range value of around 30 or 50, the spread prioritize further targets instead of the closest/closer targets. No idea, why.

### redscript version:
- Open any menu, go to "Mod Settings" and change the values for any specific quick hack or use a global settings. Do not forget to hit `APPLY`.
- "Staggered Spread" means that the spreaded hacks start uploading one after another: after the inital hack finishes uploading, the first spread starts uploading. After that first spread is finished, the second spread is uploading, and so forth.

## Uninstall
Close the game and delete the "UltimateSpreader" folders from (depending on installed version):
   1) `"Cyberpunk 2077\bin\x64\plugins\cyber_engine_tweaks\mods"` or
   2) `"Cyberpunk 2077\r6\scripts"`
